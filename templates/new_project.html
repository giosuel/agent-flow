Steps

  1. Install flow, once per machine. It signs the machine in with your approval here.

    curl -fsSL {{ public_url }}/install.sh | sh

  2. In the project's folder. Press Enter at the code prompt to create the project (you approve it here); it names the project after the folder unless you give another name.

    cd ~/my-project && flow project setup
